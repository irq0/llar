# Save to LLAR privacy notice

Save to LLAR has no telemetry and does not send data to its developer or to
third parties.

The extension stores the user-provided LLAR capture URL and authentication
token in the browser's local extension storage. When the user clicks the
toolbar button, it transfers the current page URL and that token only to the
LLAR service configured by the user. This transfer is the extension's sole
purpose and occurs only after a toolbar click.

The configured LLAR instance controls its own processing and retention of
captured URLs. Removing the extension deletes the settings held by Firefox;
data already sent to LLAR must be managed on that LLAR instance.
